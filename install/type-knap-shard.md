# Shard

A shard is a package of the kind `shard`: a self-contained program for agents that extends what an agent can do inside a Flint. It has a source (the files that a person edits) and a build (the shard that agents load). A shard gives an init file, skills, workflows, templates, knowledge, and install files, and it can define artifact types with their lifecycles. A module is the other package kind: a shard serves agents, and a module serves the machine with code that runs as a process.
